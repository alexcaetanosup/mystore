Acadia Frontend Developer
 Front-End Developer Skills Test

Create a responsive product card layout using mobile-first
HTML/CSS, then enhance it with JavaScript DOM interactions.  Please make any necessary assumptions.

Submission options:

1. Hosted html/css/js files that are viewable/accessible by us

2. Submit html/css/js files in a zip file that we can extract and run. Name all individual files and the zip file as your Full Name as it is on your resume.

Part 1 — HTML + CSS (Responsive / Mobile-First)

Requirements:

Build a small product grid containing 3 product cards.

Each card must include:

- Product image

- Product title

- Short description

- Price

- “Add to Cart” button

Responsive requirements:

- Mobile-first styling required

- On mobile (<768px): Cards stack vertically (1 column)

- Tablet (≥768px): 2 columns

- Desktop (≥1024px): 3 columns

- Images should scale fluidly

- Layout should avoid horizontal scrolling at all sizes

Part 2 — JavaScript DOM Tasks

Using vanilla JavaScript only:

Button Interaction - When a user clicks Add to Cart:

- Toggle button text between: “Add to Cart” & “Added”

- Toggle a visual style change on the card (class added/removed)

Search / Filter Feature

- Add a search input above the grid.

Requirements:

- Typing filters cards by product title (case-insensitive)

- Non-matching cards should hide dynamically

- No page reloads

Part 3: DOM Creation Task

Add a button: “Add Sample Product”

When clicked:

- Dynamically insert a new product card into the grid

- Card must match existing structure/styles

- All JS functionality should work on the new card
